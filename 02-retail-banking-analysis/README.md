# Retail Banking – Transaction & Customer Behaviour Analysis

## Project Overview
An intermediate-level data analytics project exploring banking customer transactions, spending behaviour, transaction channels and potential risk indicators.

## Business Objectives
- Analyse customer transaction patterns.
- Identify high-value customers.
- Compare debit and credit activity.
- Identify unusual transaction behaviour.
- Build an interactive banking dashboard.

## Tools
- Google Sheets
- SQL (planned)
- Power BI (planned)

## Dataset
Simulated banking transaction data.
